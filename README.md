# AHLTV Open Tour

Статичний сайт для реєстрації команд на AHLTV Open Tour + Supabase Auth/Database + адмін-панель.

## Уже є
- головна сторінка турніру;
- форма реєстрації команди;
- 5 основних гравців + заміна;
- заявка зберігається в Supabase;
- окрема `admin.html`;
- вхід через Supabase Auth;
- перевірка прав через `admin_users`;
- адмін може підтверджувати, відхиляти та видаляти заявки;
- RLS-політики для захисту даних;
- для кожного турніру можна обирати шрифт назви (7 локальних шрифтів з підтримкою кирилиці);
- сторінка турніру з зручним інтерфейсом: підсвітка шрифту, полоса заповнення, статус-пілот, таймер до початку, фільтр/сортування команд, лайтбокс сітки, список правил.

## Панель адміністратора

Після входу користувач із записом у `admin_users` бачить огляд турнірів і заявок. У панелі можна:

- шукати турніри, редагувати їх, змінювати статус, реєстрацію, видимість **та шрифт назви** (з живим прев'ю);
- фільтрувати заявки за статусом і турніром, шукати команди та розгортати контакти й склад;
- додавати команди вручну, завантажувати дві сітки, керувати користувачами та налаштуваннями сайту.

На телефоні розділ обирається у списку під заголовком. Звичайні користувачі, як і раніше, потрапляють у кабінет капітана. Дані й права доступу залишаються в Supabase.

## Підключення Supabase
1. Створити окремий Supabase project.
2. Виконати `supabase/schema.sql`.
3. У `supabase-config.js` вставити Project URL і Publishable key.
4. Створити потрібний акаунт у Supabase Auth.
5. Додати UUID цього користувача в `public.admin_users`.

Паролі та service_role/secret ключі в GitHub не зберігати.

## Локальний перегляд

Сайт не потребує збірки. Запусти в корені репозиторію:

```sh
python3 -m http.server 8000
```

Після цього відкрий `http://localhost:8000`. Для авторизації, завантаження турнірів та іконок потрібне підключення до Supabase та CDN модулів. Шрифт Manrope зберігається локально в `assets/fonts` разом із ліцензією.

## Анімація входу

При прямому відкритті сайту або оновленні сторінки коротка заставка показується приблизно секунду; переходи всередині сайту її пропускають. Заставка не чекає на Supabase чи CDN і не показується, якщо користувач увімкнув зменшення руху. Її стилі та безпечне завершення знаходяться в `motion.css` та `intro.js`.

## Перевірки

Для браузерних тестів потрібні Node.js 20+, npm і Python 3:

```sh
npm ci
npx playwright install chromium
npm test
```

Тести використовують мок Supabase і не змінюють робочі дані.
